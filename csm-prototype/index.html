DATA TRUST

데이터 원본과 검증 기준

원본에서 읽는 값, 교차검증에 쓰는 값, 일치 판정 방식까지 공개합니다. 선택한 회사와 기간의 실제 출처·표 번호·파싱 과정·검증 결과도 아래에서 추적할 수 있습니다.

STANDARD PROCESS

원본 수집부터 확정까지

  1. 01
    DART 원본 수집

    사업·분기·반기보고서의 별도재무제표와 보험계약 주석을 읽습니다. CSM은 발행 보험계약만 사용하고 출재 재보험은 제외합니다.

  2. 02
    기준 통일·재계산

    원문 단위를 십억원으로 통일하고, 표가 상품군·측정모형별로 나뉜 경우 합산합니다. 기말 CSM과 Movement 산식도 다시 계산합니다.

  3. 03
    외부 교차검증

    보험손익·순이익·지급여력은 FISIS를 우선 사용합니다. FISIS에 없는 CSM과 Movement는 각 회사 공식 IR·경영공시로 검증합니다.

  4. 04
    판정·이력 보존

    원 단위 허용오차와 표시단위 반올림을 구분해 판정합니다. 연결·별도처럼 기준이 다르면 억지로 일치시키지 않고 차이를 명시합니다.
