# CSM Lens Workbench Redesign Plan

## Goal

CSM Lens를 긴 스크롤형 대시보드에서 좌측 그룹 내비게이션, 중앙 작업 캔버스, 우측 AI 보조 패널을 갖춘 분석 워크벤치로 재구성한다. 목표는 보험 CSM 데이터를 검증하고 비교하고 전망하는 흐름을 한 화면 단위로 분리해, 컨설팅 리서치 제품처럼 신뢰감 있게 보이도록 만드는 것이다.

## Scope

- 전체 앱 쉘을 `left navigation + main canvas + right assistant` 구조로 변경한다.
- 전체 페이지 스크롤 의존을 줄이고, 탭 전환으로 기능 맥락을 이동한다.
- 기존 탭은 유지하되 화면 책임을 명확히 한다.
- AI는 독립 화면이 아니라 우측 보조 패널로 둔다.
- 현재 회사, 기간, 데이터 성격, 검증 상태가 항상 보이도록 한다.
- 깨진 한국어 UI 문구를 함께 정리한다.

## Navigation Model

- Monitor
  - 개요
  - 회사 분석
- Compare
  - 시장 비교
- Forecast
  - 전망
- Trust
  - 데이터 품질

## Screen Responsibilities

- 개요: 핵심 KPI, 검토 필요 항목, 최근 변동, 빠른 이동.
- 회사 분석: 선택 회사의 Movement, 손익, 포트폴리오, 추세.
- 시장 비교: 복수 보험사 비교, 정렬, 필터, 상세 비교.
- 전망: 최신 검증 기간 기준의 다음 연말 전망과 Movement 전망.
- 데이터 품질: 출처, 검산, 휴먼 리뷰, 보정 이력.

## Implementation Steps

- [x] HTML 앱 쉘을 좌측 내비, 상단 필터, 중앙 캔버스, 우측 AI 패널 구조로 재배치한다.
- [x] 기존 `data-tab` 기반 탭 동작을 유지하면서 좌측 내비 버튼으로 연결한다.
- [x] CSS에서 앱 전체 높이를 뷰포트 기준으로 고정하고, 중앙/우측 패널만 필요한 내부 스크롤을 허용한다.
- [x] 샘플 이미지의 분위기를 참고해 밝은 배경, 얇은 보더, 작은 라운드, 절제된 포인트 컬러를 적용한다.
- [x] JS 동작 검증과 로컬 렌더 확인을 수행한다.

## Interaction Fixes

- 탭 패널은 `hidden` 속성이 기존 `.tab-panel { display: grid; }` 스타일에 덮이지 않도록 CSS에서 명시적으로 숨긴다.
- `AI 열기` 버튼은 데스크톱에서도 우측 드로어를 여는 명령으로 동작한다.
- 제품 표시명은 `CSM Lens system`으로 통일한다.

## Non-Goals

- 데이터 계약이나 파이프라인 산식을 변경하지 않는다.
- AI 응답 계약을 변경하지 않는다.
- 다수 보험사 추가나 실제 신규 데이터 파싱은 이번 UI 구조 변경 범위에 포함하지 않는다.
