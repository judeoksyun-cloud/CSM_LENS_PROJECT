# 관리기준 예실차 수집·파싱·검증 표준

최종 갱신: 2026-08-21

## 1. 문서 목적

이 문서는 CSM Lens의 `05 예실차 > 관리기준` 데이터를 다음 결산에도 같은 방식으로 갱신하기 위한 실행 기준이다. 수치 정의, 원본 선택, 파싱 항목, 검증등급, 결측 처리, 화면 표시를 함께 고정한다.

상세 회사별 원본과 현재 확정값은 [DATA_METHODOLOGY.md](../DATA_METHODOLOGY.md)의 `예실차 · 관리기준`을 따른다. 두 문서가 충돌하면 최신 날짜의 `DATA_METHODOLOGY.md`와 정규화 JSON을 우선한다.

## 2. 변경할 수 없는 핵심 원칙

- 원본은 각 보험사 공식 홈페이지의 연말 결산 `별도 SAP 손익계산서`, 공식 Factsheet 또는 결산 경영공시다.
- 일반 GAAP 연결 손익계산서, Open DART 연결주석, FISIS, 기사, 증권사 표는 이 지표의 원본이 아니다.
- Open DART와 FISIS에 유사 숫자가 있더라도 SAP 관리기준 결측값을 보충하지 않는다.
- `ref_data`와 사용자 첨부 엑셀은 양식·행 순서 참고용이며 원본, 검증값, 보정값으로 사용하지 않는다.
- 공시는 연말만 저장한다. 존재하지 않는 연도나 분모는 추정하지 않고 `null`로 남긴다.
- 화면 표시용 반올림과 원본 저장 정밀도를 분리한다.

## 3. 지표 정의

```text
실제보험금 = 발생보험금 + 발생사고요소조정
보험금 예실차 = 예상보험금 - 실제보험금

예상사업비 = 예상손해조사비 + 예상계약유지비 + 예상투자관리비
실제사업비 = 발생손해조사비 + 발생계약유지비 + 발생투자관리비
사업비 예실차 = 예상사업비 - 실제사업비

종합 예실차 = 보험금 예실차 + 사업비 예실차
보험금 예실차비율 = 보험금 예실차 / 예상보험금
사업비 예실차비율 = 사업비 예실차 / 예상사업비
종합 예실차비율 = 종합 예실차 / (예상보험금 + 예상사업비)
```

양수는 예상액이 실제액보다 큰 우호적 경험차, 음수는 실제액이 예상액보다 큰 비우호적 경험차다. 손해조사비는 이 시스템의 관리기준에서는 사업비에 포함한다.

## 4. 원본 선택 우선순위

1. 회사 공식 홈페이지의 결산 Factsheet 안에 있는 별도 SAP 손익계산서 세부 행
2. 회사 공식 홈페이지의 결산 경영공시가 기술한 보험금·사업비 예실차 결과금액
3. 같은 회사의 공식 별도 감사보고서에서 동일 SAP 기준의 예상금액 분모가 확인되는 경우에 한해 비율 계산에 결합

세부 행과 공식 결과금액이 모두 있으면 세부 행을 재계산하고 공식 결과금액과 대조한다. 서로 다르면 자동 확정하지 않고 원단위, 부호, 손해조사비 분류, 기타 보험서비스비용 포함 여부를 다시 확인한다.

## 5. 파싱 필드와 저장 계약

정규화 파일은 `external-data/management-experience-2025.json`, 브라우저 산출물은 `csm-prototype/management-experience-data.generated.js`다.

회사별 `periods[YYYY-ye]`에는 다음을 저장한다.

| 구분 | 필드 | 설명 |
| --- | --- | --- |
| 결과 | `claimExperience` | 보험금 예실차, 억원 |
| 결과 | `expenseExperience` | 사업비 예실차, 억원 |
| 결과 | `totalExperience` | 두 예실차 합계, 억원 |
| 비율 | `ratios.total/claim/expense` | 대응 예상금액 대비 %, 분모 미공개 시 `null` |
| 구성 | `components.expectedClaims` | 예상보험금 |
| 구성 | `components.incurredClaims` | 발생보험금 |
| 구성 | `components.incurredClaimAdjustment` | 발생사고요소조정 |
| 구성 | `components.expectedExpenseTotal` | 예상사업비 합계 |
| 구성 | `components.actualExpenseTotal` | 실제사업비 합계 |
| 추적 | `source` | 발행회사, 문서명, 범위, 시트·페이지·열·행, 공식 URL |
| 예외 | `coverageNote` | 분모·세부 행 미공개와 계산 제한 |

원문의 분리된 사업비 항목을 합산한 경우 파싱 작업 로그에는 원래 행 이름과 값을 보존한다. 화면 계약에는 합계가 들어가더라도 원문 추적 위치는 반드시 남긴다.

## 6. 파싱 순서

1. 회사와 결산연도를 고정한다.
2. 공식 도메인의 결산 문서인지 확인한다.
3. 별도 SAP 범위인지 확인한다. 연결 또는 일반 GAAP 표이면 제외한다.
4. 문서명, 시트·페이지, 당기 열과 비교 열, 원단위를 기록한다.
5. 예상보험금, 발생보험금, 발생사고요소조정을 읽는다.
6. 예상·발생 손해조사비, 계약유지비, 투자관리비를 읽고 각각 합산한다.
7. 원·천원·백만원·억원을 억원으로 환산하고 괄호·삼각형·마이너스를 음수로 통일한다.
8. 세 결과금액과 세 비율을 계산한다.
9. 원문이 제공한 결과금액이 있으면 재계산값과 대조한다.
10. 원본 위치, 검증등급, 결측 사유를 결과와 함께 저장한다.

## 7. 검증등급

### `official_component_recalculated` · 세부항목 재계산

예상·발생 구성항목을 공식 SAP 표에서 읽어 아래 항등식과 비율을 모두 재계산한 경우다. 현재 삼성생명, 한화생명, 삼성화재, 메리츠화재, DB손해보험, 현대해상이 해당한다.

### `official_reported_outcome` · 공식 결과값

회사가 결산 경영공시에 기술한 보험금·사업비 예실차 금액을 사용한 경우다. 현재 교보생명, 신한라이프, KB손해보험이 해당한다. 공개된 예상금액 분모가 같은 기준으로 확인될 때만 비율을 계산한다.

### `null` · 분모 또는 값 미공개

다른 지표나 전년도 값으로 대체하지 않는다. JSON은 `null`, 본문과 전체보기는 `—`로 표시하고 `coverageNote`에 이유를 남긴다.

## 8. 검산 규칙

```text
expectedClaims - incurredClaims - incurredClaimAdjustment = claimExperience
expectedExpenseTotal - actualExpenseTotal = expenseExperience
claimExperience + expenseExperience = totalExperience
claimExperience / expectedClaims × 100 = ratios.claim
expenseExperience / expectedExpenseTotal × 100 = ratios.expense
totalExperience / (expectedClaims + expectedExpenseTotal) × 100 = ratios.total
```

세부항목 재계산은 원문 정밀도에서 수행하고 원문 표시단위의 반올림 차이만 허용한다. 공식 결과값만 있는 회사는 연도·부호·원단위·별도 여부를 확인하며 세부 항등식 검산을 통과한 것으로 표시하지 않는다.

## 9. 기간 선택 규칙

- 상단 기준기간이 1~3분기면 직전 연말을 당기로 선택한다.
- 상단 기준기간이 4분기 또는 연말이면 해당 연말을 당기로 선택한다.
- 당기의 직전 연말만 전기로 찾는다.
- 현재 수록값은 2024·2025년말뿐이다.
- 2025년말 기준은 2024 전기·2025 당기다.
- 2024년말 기준은 2023 전기 `—`·2024 당기다. 2023 값과 전년비를 만들지 않는다.

## 10. 회사별 현재 예외

- 삼성생명: 세 사업비 항목이 `계약유지관리비` 합계로 제시되므로 예상·실제 합계 차이를 사용한다.
- 교보생명: 공식 결과금액과 별도 감사보고서의 동일 기준 예상금액을 결합해 비율을 계산한다.
- 신한라이프: 예상보험금과 예상사업비 분모가 합산 공개되어 종합 비율만 계산하고 보험금·사업비 비율은 비워 둔다.
- 현대해상: 요약 `Expense differences`에 포함된 사용자 산식 밖 기타 보험서비스비용을 제외하고 예상사업비−실제사업비를 사용한다.
- KB손해보험: 결과금액은 공식 확인했지만 SAP 예상금액 분모가 없어 세 비율을 비워 둔다.

## 11. 화면 표시 규칙

- 본문 순서는 `종합 예실차 → 보험금 예실차 → 사업비 예실차`다.
- 본문은 전기·당기 비율만 소수점 첫째 자리로 표시한다.
- 전체보기는 선택 연도의 전기·당기·전년비와 금액·비율·구성항목을 표시한다.
- ±5%는 업무상 참고선이며 자동 통과·실패 판정 기준으로 쓰지 않는다.
- 생명보험과 손해보험을 구분하고 회사별 원본 링크와 검증등급을 표시한다.

